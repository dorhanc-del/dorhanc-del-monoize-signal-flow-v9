# Monoize V11.3 — Highest Final Grade Only

Teacher Studio → Grades & Results now shows one row per student per assignment, selecting the highest **final recorded score**, after the second-attempt penalty and 50% equity floor. In a tie, the most recent submission is shown. CSV export matches this view. Existing submission history remains saved on the server; nothing is deleted. Reset attempts and Delete All Grades still work.

Upload the `public` folder (and its two files) into the repository root, replacing `public/teacher.js` and `public/teacher.html`. Do not upload the ZIP itself. This patch assumes V10.12 is installed.
